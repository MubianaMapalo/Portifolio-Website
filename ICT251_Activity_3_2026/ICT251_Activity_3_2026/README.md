# ICT251 Activity 3 - Interactive Personal Website

## Project
This is a simple HTML5, CSS and JavaScript student portfolio for ICT251 Web Technologies Activity 3.

## Files
- index.html
- css/styles.css
- js/script.js
- images/
- videos/
- audio/

## JavaScript Features
1. Contact form validation and local preview
2. Expandable project details
3. Project/skills search and filter
4. Gallery Previous/Next controls
5. Mobile navigation

## Personal Content
Replace the placeholders in index.html with your own:
- Name
- Programme
- About Me paragraph
- Hobbies
- Learning plan
- Photos and captions
- Video and audio
- Projects/skills
- GitHub link

## Testing
Open index.html with VS Code Live Server and check the browser Console for errors.

## Render
For a static site on Render:
- Root Directory: blank when index.html is at repository root
- Build Command: echo "No build required"
- Publish Directory: .
- Auto Deploy: enabled
